# Divide and Conquer Exercises

Two hands-on exercises for practising the divide-and-conquer algorithms in Python (download the `DC_exercizes.ipynb` notebook).

## Exercises

### 1. Summing a List
Compute the sum of a list of numbers recursively — no `sum()`, no loops.
Introduces the core divide / conquer / combine structure in a simple setting.

### 2. Tower of Hanoi
Move N disks from one rod to another following the classic rules.
Shows how a seemingly impossible problem collapses into three lines once you think recursively.
